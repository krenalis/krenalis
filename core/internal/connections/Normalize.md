# Go values accepted on import

Krenalis accepts the following Go representations for property values read through Application `Records`, Database `Query`, and File `Read`. It normalizes each value according to the declared property type. For the Go values passed to connectors on export, see [Go values for property types](../../../tools/types/Values.md).

## Accepted inputs by kind

“Numeric inputs” in the table means `int`, `int8`, `int16`, `int32`, `int64`, `uint`, `uint8`, `uint16`, `uint32`, `uint64`, `float32`, `float64`, `decimal.Decimal`, `string`, or `[]byte`. Byte slices for numeric properties contain text. The package names `decimal` and `json` refer to [tools/decimal](../../../tools/decimal) and [tools/json](../../../tools/json).

| Kind                 | Accepted Go inputs                                            | Conversion                                                                                              | Example (input → normalized value)                                                        |
|----------------------|---------------------------------------------------------------|---------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| `StringKind`         | `string`, `[]byte`                                            | Valid UTF-8 satisfying the string constraints and semantics.                                            | `[]byte("Ada")` → `"Ada"`                                                                 |
| `BooleanKind`        | `bool`, `string`                                              | The two accepted strings are `"true"` and `"false"`.                                                    | `"false"` → `false`                                                                       |
| `IntKind` (signed)   | Numeric inputs                                                | Whole number in the signed range. Text is parsed in base 10.                                            | `[]byte("-57")` → `int(-57)`                                                              |
| `IntKind` (unsigned) | Numeric inputs                                                | Supply a nonnegative whole number in the unsigned range. Text is parsed in base 10.                     | `float64(3)` → `uint(3)`                                                                  |
| `FloatKind`          | Numeric inputs                                                | Text is parsed at the declared bit width. See numeric conversions below.                                | `"1.5"` → `float64(1.5)`                                                                  |
| `DecimalKind`        | Numeric inputs, `fmt.Stringer`                                | Convert at the declared precision and scale, then check the decimal range.                              | `"6.639e2"` → `decimal.MustParse("663.9")`                                                |
| `DateTimeKind`       | `time.Time`, `string`, `float64`                              | Convert the instant to UTC. Numeric input requires a Unix layout.                                       | `"0"` with `unix` → `time.Unix(0, 0).UTC()`                                               |
| `DateKind`           | `time.Time`, `string`                                         | Convert to UTC, then take the calendar date at midnight.                                                | `"2024-01-01"` → `time.Date(2024, 1, 1, 0, 0, 0, 0, time.UTC)`                            |
| `TimeKind`           | `time.Time`, `string`, `[]byte`                               | Keep the clock fields and nanoseconds. Set the date to 1970-01-01 and the location to UTC.              | `[]byte("09:30")` with `15:04` → `time.Date(1970, 1, 1, 9, 30, 0, 0, time.UTC)`           |
| `UUIDKind`           | `string`, `[]byte`                                            | Supply a hyphenated UUID string or exactly 16 binary bytes. The result is a lowercase UUID string.      | `make([]byte, 16)` → `"00000000-0000-0000-0000-000000000000"`                             |
| `JSONKind`           | `json.Value`, `string`, `[]byte`, `json.Marshaler`            | Supply one valid JSON value. For a marshaler, `MarshalJSON()` must succeed and return valid JSON bytes. | `"null"` → `json.Value("null")`                                                           |
| `IPKind`             | `string`, `net.IP`, `netip.Addr`                              | Check prefix length (IPv4 0–32, IPv6 0–128). Drop prefix and zone. Unmap IPv4-mapped IPv6 addresses.    | `"192.168.1.10/24"` → `"192.168.1.10"`                                                    |
| `ArrayKind`          | Any Go slice, or `string` for `array(json)`                   | Normalize each element to the declared element type. Check length and any uniqueness constraint.        | `[]int16{7}` for `array(int(32))` → `[]any{int(7)}`                                       |
| `ObjectKind`         | `map[string]any`                                              | Normalize declared properties in place. Drop extra keys. Only `ReadOptional` properties may be absent.  | `map[string]any{"active": "true"}` for a boolean field → `map[string]any{"active": true}` |
| `MapKind`            | Any Go map with string-kind keys, or `string` for `map(json)` | Require valid UTF-8 keys. Normalize each map value to the declared element type.                        | `map[string]int16{"n": 7}` for `map(int(32))` → `map[string]any{"n": int(7)}`             |

## Numeric and temporal conversions

- Integer properties accept floating-point and decimal inputs only for integral values within range. Text must parse as an integer. For example, `float64(3.0)` and `"3"` are accepted, while `"3.0"` fails to parse.
- For a `float(32)` property, integer, finite floating-point, and decimal inputs must be exactly representable in `float32`. Krenalis checks decimal inputs with `Decimal.Float32()`. Text is parsed at the declared bit width and may round. For example, a `float(32)` property rejects `int32(16777217)` and reads `"16777217"` as `16777216`. For a `float(64)` property, decimal inputs must convert successfully with `Decimal.Float64()`. Inputs of type `int`, `int64`, `uint`, and `uint64` have an additional magnitude limit of 2²⁴ for `float(32)` properties and 2⁵³ − 1 for `float(64)` properties. The declared range applies to finite values and infinities. A `real` property requires a finite value.
- Decimal properties accept decimal text, including scientific notation. Text, `fmt.Stringer.String()`, and decimal inputs must fit the declared precision and scale exactly. Finite floating-point inputs are rounded to the scale, with ties to even.
- Krenalis uses an ISO 8601 date-time parser by default. To import a time without a date, such as `"09:30"`, set `TimeLayouts.Time` to `"15:04"` (see [issue #2804](https://github.com/krenalis/krenalis/issues/2804)). For other provider-specific formats, set the corresponding `TimeLayouts` field to the Go layout. Datetimes and dates must have a UTC year in 1–9999. For times of day, the clock fields are preserved even when the input carries an offset.
- With a `DateTime` layout of `unix`, `unixmilli`, `unixmicro`, or `unixnano`, return a base-10 signed 64-bit integer string or a finite `float64` in the signed 64-bit interval [−2⁶³, 2⁶³). A float in seconds can include fractional seconds. The other three units truncate fractional input toward zero. Use a string to preserve large nanosecond counts exactly.

## Collections, semantics, and nulls

For Go slices and maps, array elements and map values are normalized recursively with nullability disabled. Object properties use their own `Nullable` and `ReadOptional` flags.

The string form of `array(json)` must begin with `[`, and the string form of `map(json)` must begin with `{`. JSON validation applies to both string forms and to JSON data supplied for `JSONKind`, including the output of `MarshalJSON()`. The data must contain one valid JSON value encoded in UTF-8. Unicode escapes must represent valid Unicode characters, and names must be unique within each object. In the two string forms, each immediate array element or object member value becomes one `json.Value`, including the literal `null`. For example, `[{"n":1}]` yields a slice with one `json.Value` containing the entire object `{"n":1}`.

Country strings must be valid codes in the declared ISO 3166 format. A phone string may contain at most 250 bytes before trimming leading and trailing whitespace. After trimming, it must start with `+` and contain a single complete international number without an extension. The result is in E.164 format, for example `"+39 02-36618 300"` becomes `"+390236618300"`. Other semantics use the input representations of the underlying kind.

In a record or object represented by a Go map, omit the key to leave a read-optional property absent. For file imports, `RecordSlice` requires one value per declared column. `RecordStrings` fills missing trailing columns with `""` before normalization, so a string property that accepts the empty string is present with value `""`.

For a nullable JSON property, `[]byte(nil)` and `json.Value(nil)` produce Go `nil`. If the connector supplies a custom `json.Marshaler`, Krenalis calls `MarshalJSON()` even when the receiver is nil. Returning the JSON literal `null` produces `json.Value("null")`. For a decimal property, Krenalis also calls `String()` on a `fmt.Stringer` with a nil receiver.

A Go `nil` input requires a nullable property. For nullable arrays, objects, and maps, a nil slice or map of an accepted type produces Go `nil`. The same applies to nil byte slices accepted as scalar inputs, such as `[]byte(nil)` for a string or `net.IP(nil)` for an IP address.

On a non-nullable property, a typed nil follows the conversion for its kind. For example, `[]byte(nil)` becomes `""` for a string that permits an empty value, a nil slice becomes `[]any{}` for an array that permits zero elements, and a nil map with string-kind keys becomes an empty map for `MapKind`.

On nullable decimal, datetime, date, time, UUID, JSON, and IP properties, an empty Go string becomes `nil`. The same applies to country and phone strings, and to an empty string rejected by an enumeration or pattern. An allowed empty string stays `""`. A non-nil empty byte slice follows the byte conversion for its kind.

See the [normalizer](normalize.go) and its [accepted and rejected examples](normalize_test.go).
